# 寻迹 · 校园失物招领

2026 秋软件工程第二次结对作业（程序实现）—— 一个零依赖、双击即用的校园失物招领网页。

- **成员**：冯安娜（102401402）· 李思淇（052401304）
- **技术栈**：纯 HTML + CSS + 原生 JavaScript（无框架、无构建、无后端）
- **数据**：浏览器 localStorage 本地持久化

## 功能一览

| 功能 | 说明 |
|---|---|
| 发布信息 | 寻物 / 招领两种类型，逐字段校验（必填 / 长度 / 时间格式），发布前相似信息提醒 |
| 浏览信息 | 统计条 + 类型 Tab + 类别 / 区域 / 状态组合筛选 + 一键重置 |
| 搜索信息 | 多关键词（空格分隔、全部命中），大小写 / 全半角归一化，空状态引导 |
| 查看详情 | 完整信息 + 状态时间线 + 相似线索推荐（可核对的中文理由） |
| 联系发布者 | 弹窗展示联系方式 + 一键复制（Clipboard API 失败自动降级） |
| 更新状态 | 发布者标记「已找到 / 已归还」、可改回进行中、删除（二次确认） |
| 我的发布 | 集中管理自己发布的信息 |
| 附加体验 | 发布草稿恢复、搜索历史、相对时间、演示数据防篡改 |

## 使用说明（测试人员版）

### 运行网页

1. 下载 / `git clone` 本仓库全部文件到本地，**保持目录结构不变**；
2. 用**谷歌浏览器（Chrome）** 双击打开 `index.html`（或双击 `start.cmd`）；
3. 无需安装任何软件、无需联网、无需后端服务器。

### 核心流程走查建议

1. **浏览**：首页查看统计条、类型 Tab、类别/区域/状态筛选，试试「一键重置」；
2. **搜索**：输入 `校园卡`、`图书馆 保温杯`（多关键词）、`Ａｉｒ`（全角）分别体验；
3. **详情**：点卡片查看详情 → 「联系发布者」弹窗 → 一键复制联系方式；
4. **发布**：底部「发布」填表单——先试试**留空必填项**看红字提示、**超长名称**被拒绝、**非法时间**（如 2026-02-30）被拒绝；
5. **相似提醒**：发布一条与示例「蓝色雨伞」名称相似的招领，观察相似信息提醒弹窗；
6. **状态闭环**：发布成功后进「我的发布」→「标记为已找到/已归还」→ 回首页看卡片置灰沉底、统计条数字变化 → 详情页时间线出现标记记录 → 再「改回进行中」；
7. **删除**：我的发布中删除一条自己发布的信息（走二次确认）；
8. **演示数据**：示例数据（8 条）不显示操作按钮，不可修改、不可删除。

### 注意事项

- 数据保存在本机浏览器的 localStorage 中；换浏览器 / 换电脑数据不同属正常现象；
- 想重置为初始示例数据：按 F12 打开控制台，执行 `localStorage.clear()` 后刷新页面；
- 无登录的纯前端中，「我的发布」用本机 `ownerId` 识别发布者，仅用于演示操作边界，不提供真实身份认证与跨设备数据同步（README 与界面均说明该限制）。
