## 使用说明

1. 下载本仓库全部文件，**保持目录结构不变**；
2. 用**谷歌浏览器（Chrome）** 双击打开 `index.html`；
3. 无需安装任何软件、无需联网、无需后端服务器。

## 单元测试

- 工具：Node.js 内置 `node:test`（Node 18+ 自带）
- 运行方式（项目根目录）：

```bash
node --test
```
